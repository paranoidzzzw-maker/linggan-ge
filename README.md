# 灵感阁 · 网文创作 AI 助手

一个单文件的网页应用，给你对象在浏览器里跟 AI 聊小说、找灵感用。它内置了一套从 `webnovel-writing` 技能提炼出来的中文网文写作方法论，不是普通的“随便聊聊”聊天框。

## 快速开始

1. 双击打开 `index.html`（用 Chrome / Edge 都可以）。
2. 点右上角 ⚙，选一个服务商，填上 API Key，保存。
3. 在左侧选一个“写作模式”，然后在输入框里说说想写的小说，开始聊。

没有 API Key 也可以先点“看一个示例回答”体验界面。

## 支持的服务商

- DeepSeek（推荐，便宜、国内直连）
- OpenAI
- 通义千问（阿里云百炼）
- Kimi 月之暗面
- 智谱 GLM
- 自定义（任何 OpenAI 兼容接口）

API Key 只保存在你本机浏览器的 localStorage 里，不会上传到任何服务器。

## 内置的写作模式（规则移植自 webnovel-writing 技能）

- 自由灵感：把模糊念头聊成能写的设定
- 点子评估：题材、卖点、hook、premise、故事引擎、第一卷方向
- 开头写法：黄金三章成交，300 字给抓手、1500 字给卖点
- 章纲规划：黄金三章、分卷、前 10–20 章章纲（每章目标/冲突/新信息/章末拉力）
- 单章写作：每章四问 + 场景目标/阻碍/变化 + 六项一致性自查
- 局部修复：按信号路由到转场/对白/章末/因果/人设，对症修
- 去 AI 味：动作化、具体化、带身份感的改写
- 完稿复查：六项一致性逐条体检

每个模式都带一组可一键填写的示例提问。

## 其他功能

- 多个对话并存，自动保存在本地
- AI 回复可复制、可收藏到“灵感收藏”
- 一键导出对话或灵感为 Markdown
- 手机端自适应布局

## 常见问题

- 发送报错 401：API Key 填错或失效。
- 发送报错 404：接口地址或模型名不对，去对应服务商文档核对。
- 浏览器报 CORS 错误：该服务商不允许浏览器直接调用，换一个支持直连的服务商，或给本页配一个简单的后端代理。

> 说明：本页直接调用各家 OpenAI 兼容接口，需要对应服务商允许浏览器跨域请求。DeepSeek 等主流服务商支持直连。
